# TinyBunny-Belarusian
Беларускі пераклад (Беларусіфікатар) для гульні Tiny Bunny («Зайчык»), эп. 1–5 | Belarusian Translation

=====================================================================

Сумяшчальнасць: Tiny Bunny v5.1.5 (Steam / Windows)
Ахоп перакладу:
- Інтэрфейс, меню, налады, слоўнік і міні-гульні
- Газетныя канцоўкі і экран схемы выбараў
- Эпізоды 1, 2, 3, 4 і 5 (поўны пераклад усіх 5 эпізодаў цалкам без цэнзуры, з захаваннем арыгінальнага стылю, жаргону і жартаў)

---------------------------------------------------------------------
УСТАНОВКА (для Steam-версіі і звычайнай версіі)
---------------------------------------------------------------------
1. Адкрыйце папку з усталяванай гульнёй:
   У Steam: ПКМ па гульні «Зайчык» (Tiny Bunny) -> Упраўленне -> Праглядзець лакальныя файлы.
   (Там павінна быць папка «game» і файл «TinyBunny.exe»).

2. Скапіруйце папку «game» з гэтага архіва/папкі ў корань гульні
   з пацвярджэннем зліцця папак і замены файлаў (калі спатрэбіцца).

   Правільная структура пасля капіявання:
   <папка гульні>/game/scripts/sys/tl_settings/sys_belarusian.rpy (.rpyc)
   <папка гульні>/game/tl/belarusian/...

3. Запусціце гульню.
   - Пры першым запуску беларуская мова ўключыцца аўтаматычна.
   - Таксама мову заўсёды можна пераключыць кнопкай «БЕЛ» у галоўным меню.

---------------------------------------------------------------------
ВЫДАЛЕННЕ
---------------------------------------------------------------------
Каб вярнуць гульню ў зыходны стан, дастаткова выдаліць:
- папку: <папка гульні>\game\tl\belarusian\
- файлы: <папка гульні>\game\scripts\sys\tl_settings\sys_belarusian.rpy
         <папка гульні>\game\scripts\sys\tl_settings\sys_belarusian.rpyc
